Opening it the first time

It opens to a library where you can start a book, a journal or a notebook, or open one you already have.

On a Mac

Open the download and drag Quillier to Applications. It’s signed and notarized by Apple, so it opens like any other app.

On Windows

Run the installer. If Windows says it protected your PC, click More info, then Run anyway. That happens with new apps that aren’t code-signed yet.

On Linux

Make the AppImage executable, in its file properties or with chmod +x, then double-click it.

Updates

Quillier checks for a new version now and then, downloads it quietly and installs it when you quit. You can turn that off in Settings, and check by hand from the menu instead.

That check is the only time it goes online. Nothing you write ever leaves your computer.

Free and open source

Quillier costs nothing, with no subscription. The code is MIT-licensed and on GitHub, where you can read it, report a bug or suggest an idea. Every version is listed with its notes on the releases page.
